# fork-haiku 実行メタ情報

- 実施日: 2026-09-22
- 目的: `context: fork` 相当の経路で、軽いモデルに切り替えた場合の振る舞いを確認する。
- 実行方法: Claude Code の Agent ツール（`subagent_type: general-purpose`、`model: haiku`、会話履歴なし）を 1 ケース 1 エージェントで起動。プロンプトは SKILL.md の本文（frontmatter を除く全文）の末尾に正規入力 JSON を付けたもので、`context: fork` がサブエージェントへ渡す内容（スキル本文 + 引数）を再現した。追加の指示は与えていない。
- 実行モデル: Agent ツールの `haiku` 指定（Haiku 4.5）。effort はセッション既定を継承しており、`effort: low` は再現できていない。
- 観測方法: 最終メッセージ全文（`RAW.md`）。`E*.json` は最終メッセージから JSON オブジェクトを取り出したもので、E10 は JSON が無いためファイルを作っていない。E04・E07 の `explanation` 内の引用符は保存時に平文へ置き換えた。ツール呼び出し回数はハーネスの集計で全 12 件が 1 回（最終報告のみ）で、判断のための追加ツール使用はなかった。
- 制約: 実際の `/semantic-decision` 経由の fork 読み込みではない。セッション途中で追加したプロジェクトスキルは認識されなかったため、同等の入力で再現した。
- 応答時間・トークン数: 未測定。
